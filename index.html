Abstract

Melanoma is the most lethal form of skin cancer, requiring early and accurate diagnosis. While deep learning models have achieved dermatologist-level classification accuracy, their training typically requires centralizing vast repositories of sensitive patient dermoscopic images, raising significant privacy and regulatory concerns (HIPAA, GDPR). In this project, we propose a Federated Explainable AI (FedXAI) framework for decentralized melanoma classification. Our approach trains robust EfficientNet models across multi-institutional hospital nodes without sharing raw patient data, employing Differential Privacy with Stochastic Gradient Descent (DP-SGD) to provide rigorous cryptographic privacy guarantees. Furthermore, we integrate post-hoc explainability modules (Grad-CAM and LIME) to map model predictions directly to clinical ABCDE dermoscopic criteria, establishing trust and clinical interpretability.

Key Technical Contributions

  • Decentralized FedAvg & FedProx training across 4 simulated hospital nodes.
  • RDP-based Differential Privacy accountant ensuring $\epsilon < 2.5$.
  • Automated ABCDE feature attribution derived from Grad-CAM activation heatmaps.
  • Extensive evaluation on ISIC 2024 and HAM10000 benchmark datasets.

import torch
import torch.nn as nn
from torchvision import models
from opacus import PrivacyEngine

class MelanomaEfficientNet(nn.Module):
    def __init__(self, num_classes=3):
        super(MelanomaEfficientNet, self).__init__()
        self.model = models.efficientnet_b4(weights=models.EfficientNet_B4_Weights.DEFAULT)
        self.model.classifier[1] = nn.Linear(self.model.classifier[1].in_features, num_classes)
        
    def forward(self, x):
        return self.model(x)

def train_federated_node(model, dataloader, optimizer, privacy_engine, epochs=1):
    model.train()
    criterion = nn.CrossEntropyLoss()
    
    for epoch in range(epochs):
        for batch_idx, (data, target) in enumerate(dataloader):
            optimizer.zero_grad()
            output = model(data)
            loss = criterion(output, target)
            loss.backward()
            optimizer.step()
            
    epsilon = privacy_engine.get_epsilon(delta=1e-5)
    print(f"Node local training complete. Current Privacy Budget ε: {epsilon:.2f}")
    return model.state_dict(), epsilon

if __name__ == "__main__":
    net = MelanomaEfficientNet()
    print("Initialized Federated Melanoma EfficientNet-B4 Node.")
